# 🦎 YASHERICA

## 🚀 Installation

1. Create empty Project from Universal 3D template.
2. Initialize local git repository.
```bash
cd yasherica
git init
git touch temp.txt
git add temp.txt
git commit -m "Git requires local repo to have a commit"
git remote add origin https://github.com/KordenBallas/yasherica.git
git pull origin main --allow-unrelated-histories
git branch --set-upstream-to=origin/main
```
3. Install required packages.
- `Zenject` https://assetstore.unity.com/packages/tools/utilities/extenject-dependency-injection-ioc-157735
- `Cinemachine`
