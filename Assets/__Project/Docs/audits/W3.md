# W3 — Dead, Unreachable & Orphaned Code Audit

**Pass:** Track W · W3 (brief: `product-requirements/architecture-and-extensibility-audit.md`)
**Date:** 2026-07-07 · **Scope:** all runtime code under `Assets/__Project/Scripts/` (1017 `.cs` files), all assets under `Assets/__Project/` (293 `.prefab`/`.asset`, plus `.mat`/`.controller`/`.anim`/`.ink`), measured against the W3 liveness-channel rubric.
**Read-only:** this report proposes deletions; nothing was deleted. **Total confirmed+suspected surface: ~2 200 lines of C# across 24 files, 3 orphaned prefabs, 2 suspected orphan assets.**

**Method (hybrid, per the brief).** Mechanical sweep first: every declared type (1 130) counted across all `.cs` files in `Scripts/` + `Tests/`; 52 types with zero external references + 6 test-only types became candidates. Each candidate was then adjudicated against the Unity liveness channels: **(a)** GUID references from `.unity`/`.prefab`/`.asset` (SerializeField/inspector wiring), **(b)** Zenject by-type bindings in installers, **(c)** `Resources.Load`/`LoadAll` string paths (literals + consts extracted from code), **(d)** `AddComponent<T>` in code, **(e)** attributes/reflection (`[CreateAssetMenu]`, `[MenuItem]`, `[CustomEditor]`, `[Serializable]` DTOs reached through a serialized root), **(f)** extension-method call sites (class name absent at call site), **(g)** test-only usage. Assets: every non-`Resources` asset GUID-swept (result: **all 293 prefab/asset files live under `Resources/`**, so the string channel applies everywhere); `Resources` subfolders were matched against the extracted load-path set, and unmatched assets GUID-swept individually.

A candidate that could not be cleared on every channel is tagged **suspected — needs a human confirm**, never "delete".
