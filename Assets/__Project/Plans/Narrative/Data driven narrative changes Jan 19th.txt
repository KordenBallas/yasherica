 Story Graph System Implementation Plan

 Overview

 Implementing a unified story graph architecture that treats all narrative content (chapters, side stories, dialogues, events) as interconnected nodes in a story graph. This enables dynamic, connected narrative experiences where completed stories influence which new
 stories become available.

 Priority Focus: Enhanced Scenario Generation - making the generator intelligent about story connections, pacing, and player experience.

 Key Design Decisions

 1. Unified Story Architecture

 - Create BaseStoryDefinition abstract ScriptableObject
 - All story types (Chapter, SideStory, Dialogue, Event) extend this base
 - Common properties: storyId, inkAsset, relationships, attributes, prerequisites

 2. Story Graph System

 - Story Relationships: Typed edges between stories (Sequence, Branch, Prerequisite, Parallel, Exclusive, Consequence, Callback, TagMatch)
 - Story Attributes: Flexible tag/value system for dynamic connections (theme, location, emotion, etc.)
 - Graph Provider: Runtime service to query available stories based on completed stories and current state

 3. Enhanced Scenario Generation

 - Graph Traversal: Query story graph for available next stories based on relationships
 - Selection Strategies: Pluggable strategies (Linear, Balanced, Thematic, Exploration)
 - Smart Pacing: Mix main story, connected side stories, and filler based on narrative flow

 4. NPC Story Associations

 - NPCs become story carriers with role-based associations (Protagonist, Antagonist, QuestGiver, etc.)
 - Replace DialogueSessionDefinitions list with NpcStoryAssociation list
 - Support multiple NPCs in one story, one NPC in multiple stories

 4.1 Story Graph Scenario Generator

 File: Assets/__Project/Scripts/LevelGeneration/Scenario/StoryGraphScenarioGenerator.cs

 public class StoryGraphScenarioGenerator : IScenarioGenerator
 {
     private readonly IStoryGraphProvider _storyGraph;
     private readonly IStoryStateProvider _storyState;
     private readonly IStorySelectionStrategy _selectionStrategy;

     public ScenarioData GenerateScenario(GameContext context)
     {
         // 1. Get current story position in graph
         var completedStories = _storyState.CurrentState.CompletedStories;

         // 2. Query graph for available next stories
         var availableStories = _storyGraph.GetAvailableStories(_storyState.CurrentState);

         // 3. Apply selection strategy to choose stories
         var selectedStories = _selectionStrategy.SelectStories(
             availableStories,
             context,
             _storyGraph,
             maxStories: CalculateMaxStories(context)
         );

         // 4. Prioritize connected stories
         var prioritizedStories = PrioritizeConnectedStories(selectedStories, completedStories);

         // 5. Build scenario from selected stories
         return BuildScenarioFromStories(prioritizedStories, context);
     }

     private IReadOnlyList<BaseStoryDefinition> PrioritizeConnectedStories(
         IReadOnlyList<BaseStoryDefinition> stories,
         IReadOnlyList<string> completedStories)
     {
         // Stories with Sequence/Consequence relationships to completed stories
         // get higher priority for better narrative continuity
         return stories
             .OrderByDescending(story => GetConnectionScore(story, completedStories))
             .ToList();
     }

     private ScenarioData BuildScenarioFromStories(
         IReadOnlyList<BaseStoryDefinition> stories,
         GameContext context)
     {
         var scenario = new ScenarioData
         {
             DifficultyLevel = CalculateDifficulty(context, stories),
             Theme = SelectTheme(context, stories),
             ChapterId = _storyState.CurrentChapterId
         };

         var requirements = new List<PlatformRequirement>();
         requirements.Add(CreateEntryPlatform());

         // Interleave story platforms with intelligent pacing
         InterleavePlatforms(requirements, stories, context);

         scenario.RequiredPlatforms = requirements;
         scenario.EstimatedPlatformCount = requirements.Count;

         return scenario;
     }
 }

 Key improvements:
 - Relationship-aware: Prioritize stories connected to completed ones
 - Attribute-driven theme: Select level theme based on story attributes
 - Dynamic difficulty: Adjust difficulty based on story types in scenario
 - Smart pacing: Space out key story beats with filler and side content

  🚀 How to Use

  1. Enable Story Graph System

  The system is enabled by default. In your NarrativeInstaller component:
  - Check Enable Story Graph = true (default)

  2. Create Story Relationships

  In Unity Inspector, edit your StoryChapterDefinition or SideStoryDefinition:

  Relationships:
    - Relationship Type: Sequence
      Target Story: Chapter2
      Weight: 1.0
      Is Key Progression: true

  3. Add Story Attributes

  Add thematic tags to stories for dynamic connections:

  Attributes:
    - Key: "theme", Value: "betrayal", Match Type: Exact, Weight: 0.8
    - Key: "location", Value: "forest", Match Type: Contains, Weight: 0.6
    - Key: "emotion", Value: "tense", Match Type: Exact, Weight: 0.7

  4. Associate NPCs with Stories

  In NpcDefinition:

  Associated Stories:
    - Story: MerchantDialogue1
      Role: QuestGiver
      Priority: 80
      Trigger Condition:
        Type: Always

  5. Switch Selection Strategies

  To change narrative style, modify NarrativeInstaller.cs:175:

  // For focused main story:
  Container.Bind<IStorySelectionStrategy>().To<LinearStoryStrategy>()

  // For thematic coherence:
  Container.Bind<IStorySelectionStrategy>().To<ThematicStoryStrategy>()

  // For maximum exploration:
  Container.Bind<IStorySelectionStrategy>().To<ExplorationStoryStrategy>()
