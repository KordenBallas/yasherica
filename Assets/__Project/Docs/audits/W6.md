Everything else is a P2 tail that bundles into existing cleanup lanes.

## 3. The themes (initiative-shaped, ROADMAP-ready)

### Theme R1 — Combat core reconvergence *(the load-bearing one)*
**What:** extract the shared round/state engine out of `CombatController`/`ArenaCombatController` (verbatim-copy pair, 35 consumer files); lead policy, resolution order (`IArenaResolutionOrder` exists), and commit source become strategies. Split `CombatActiveState`'s 19-dependency bootstrap; its unit-spawn half lands inside the already-filed **D6** diagnose-and-unify.
**Why now:** Track K (speed initiative, pull/dash/hook) is queued next — every combat change until then must be written and tested twice or Arena silently diverges.
**Model:** Opus (Fable optional — cross-system correctness with lockstep determinism; the round-hash instrumentation is the safety net). **Cost:** ~10–15 files + arena re-verification. **Sequence:** before Track K.

### Theme R2 — Biome-as-data *(the P0 extensibility gap)*
**What:** `BiomeDefinition` SO replaces the `LevelTheme` enum as biome identity; migrate the four enum-keyed SO fields (appearance, loot, monster pool, race homeland) with the `[RaceId]`-drawer authoring pattern; extract the enum out of the doomed `ScenarioData.cs` first (W3 erratum).
**Why now:** the only designer-must-touch-code content path; the Mountain/Desert roster content wave will otherwise pile more assets onto the enum. No `switch` ladders exist — the migration is identity-only, cheaper than it looks.
**Model:** Opus. **Cost:** medium (~45 pass-through references, 4 SO field migrations + asset re-saves). **Sequence:** before the biome content wave; coordinates with Theme R4's scenario deletion.

### Theme R3 — One platform seam *(two P0 rule breaks, cheaply)*
**What:** `PlatformRegistry` static self-instantiating singleton → Zenject-bound `IPlatformRegistry` (plain class); add `GetView()` and delete `ContentSpawner`'s `GameObject.Find`/`FindObjectsByType` (§5 forbidden APIs); drop `PlatformVisual.GameObject` (the in-code TODO); re-home `ArenaPlatformBuilder` onto `PlatformView` (+ fix the `Standard`-shader fallback that renders magenta under URP).
**Model:** Opus. **Cost:** small (~8–10 files). **Payoff:** unlocks the filed `PlatformEvents`→signals migration and kills one of the three point-in-polygon copies.

### Theme R4 — Dead-code purge *(cheap, adjudicated, ready)*
**What:** execute W3's delete order — wave 1 leaves (9 files + 3 orphan prefabs), wave 2 clusters (dialogue-content lane, win-condition trio, builder cluster, scenario residue **after** the `LevelTheme` extraction and the P3-6 `StoryNodeRequirement` decision), plus W1's `IAbilityDataProvider` lane; wave 3 owner-gated items (legacy `RunDirector` lane delete-or-finish, cutscene lane keep-or-delete, `BoneMapResolver`/`SubjectContext` placement, two suspected assets, stale `"Heroes/HeroDefinition"` path). Executes filed **P6-4** en route.
**Model:** Sonnet (Haiku for wave 1) — adjudication is done; the work is mechanical but **needs a compiler + EditMode run between waves**. **Cost:** ~2 200 lines removed. **Sequence:** anytime; wave-2-D after R2 starts.

### Theme R5 — Hero movement single path
**What:** delete the dormant `AICharacterMovementController` + its disabled `Hero.prefab` component (W3-confirmed); then extract the live controller's movement/dash/platform-transition logic into a pure-C# model behind the input seam (§5/§6 compliance), killing the duplicated `SetCurrentPlatform`/`PlatformEvents`-firing block and the second geometry copy.
**Model:** Haiku (step 1) + Opus (step 2). **Cost:** small + medium. **Payoff:** removes the highest-blast-radius duplication (the platform-transition event stream feeds streaming/autosave/loot/narrative).

### Theme R6 — Layering enforcement *(the enabler)*
**What:** incremental asmdef split with `noEngineReferences: true` Core assemblies (one system per pass); sweep the dead `using UnityEngine` imports; move `AbilityShapeCalculator` off `Vector2Int`; split `Battlefield`'s world-position mapping out of the domain grid; fold the shared 2D-geometry home into the filed **P6-3** `Core.Hex` extraction.
**Model:** Sonnet (mechanical, compiler-needed); Opus for the `Battlefield` split. **Cost:** medium, amortisable. **Payoff:** W2-F7-class violations become compile errors instead of audit findings.

### Theme R7 — Small-cleanups tail *(bundle with P6-5)*
**What:** narrow interface for `DialogueRunner` in the combat/dialogue platform states; one `EventSystem` bootstrap (3 copies today); delete the three stray `Scripts/Combat/*.md` pattern-teaching relics; guard or remove the inspector-list-else-`LoadAll` hybrid (silent-override trap); create the missing `RunPacingConfig` asset so pacing is data as designed.
**Model:** Sonnet/Haiku, opportunistic. **Cost:** trivial per item.

### Theme R8 — Doc patches *(feeds W5)*
**What:** document `AIProfileDefinition` (the 1-of-57 miss); state the ability-kind factory seam and bark-slot boundary in their docs' Adding-Content sections; note the 8 dialogue assets without `.ink` sources as the known lockstep workflow.
**Model:** Haiku/Sonnet. **Sequence:** fold into the W5 pass when it runs (its worklist, §6).
