   Ключевое архитектурное решение. Новый RunDirector выбирает сюжет в рантайме по текущим фактам                                                                                                                 ↑
   на момент входа (R6/R7), а не заранее на этапе генерации. Поэтому генерация уровня перестаёт назначать
   истории NPC и начинает размещать акторов (NpcArchetype), а оркестрация выбора сюжета —                                                                                                                        ↑
   per-encounter, при входе на платформу. Логика оркестрации живёт в новом чистом C#-классе
   EncounterDirector, а DialogueActiveState остаётся тонким адаптером стейта (CLAUDE.md §3/§10).                                                                                                                 ↑

   Поток одного энкаунтера (целевой)                                                                                                                                                                             ↑

   1. DialogueActiveState.OnEnter → читает NpcContent платформы → его постоянный NpcInstance + NpcArchetype.                                                                                                     ↑
   2. EncounterDirector.BeginEncounter(actor): строит ContextBag ($self/$faction → актор) →
   RunDirector.SelectNext(storylets, factStore, context) → если есть подходящий сюжет,                                                                                                                           ↑
   CastingFactory.Cast(chosen, actor, library) → DialogueRunner.Begin(casting). Возвращает
   false, если подходящего сюжета нет (платформа корректно завершается).                                                                                                                                         ↑
   3. DialogueRunnerViewPresenter (уже забинден, NonLazy) сам ведёт IDialogueView по событиям раннера.
   4. DialogueActiveState подписан на исходы раннера: OnCombatTriggered(enemyId) → переход в бой;                                                                                                                ↑
   конец боя → DialogueRunner.ReportCombatResult(won) возобновляет диалог; OnQuestStarted →
   уже записан раннером через IRunProgressionRecorder (passthrough); OnDialogueEnded → TransitionToCompleted.                                                                                                    ↑
