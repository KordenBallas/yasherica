
Track C — Combat полностью реализован. Все 7 фаз завершены: весь проект компилируется (667 файлов, 0 ошибок), 54/54 доменных теста зелёные, документация обновлена в том же изменении.

Что построено

Фаза раунда Plan → Act → Resolve (combat-turn-intent-phase.md)
- RoundPhase + EnemyIntent на CombatState; чистые EnemyIntentPlanner (все враги решают в начале раунда, порядок по UnitId, клетки/facing снапшотятся) и EnemyIntentResolver (закоммиченный удар бьёт ровно по показанным клеткам — уклонился → промах, занятая клетка → move физлится, перенацеливания нет).
- CombatController оркеструет раунд; EnemyRoundController (заменил AITurnController) размеренно разрешает интенты. AI-скоринг не тронут; решатели сидируются от run seed (combat-ai:{enemyId}) — same seed → same plans.
- Попутно закрыт скрытый баг: раньше AI ставил абилки в очередь, но никогда их не исполнял — теперь закоммиченные касты реально стреляют.

Facing-relative aiming (combat-hero-facing.md)
- Unit.FacingDirection (HexDirection) — единственное направление на весь залп; прицеливание мышью поворачивает юнита (бесплатный, неограниченный ChangeDirectionAction, легален и после действия). Поворот между постановкой и исполнением перенацеливает всю очередь (тест-подтверждено). AbilityTarget/RetargetAbilityAction удалены. UnitFacingRotator доворачивает модель — направление читается визуально.

Displacement (push) + честное превью
- _pushDistance на AbilityDefinition + DisplacementResolver (общий для исполнения и превью); демо-ассет TestPushAbility.asset подключён врагу и герою (fallback).
- AbilityOutcomeCalculator — чистый расчёт исхода: предсказанные урон и клетки приземления равны реальному исполнению (тест-инвариант призрака).

Телеграф (combat-ability-ghost-telegraph.md)
- Иконки плана над каждым юнитом: очередь игрока по порядку, интент врага с момента раскрытия (иконка абилки или » для move).
- Ghost: на постановку в очередь один раз проигрывается полупрозрачный призрак полного исхода (клон кастера лицом по залпу + клоны сдвинутых юнитов в точках назначения + цифры урона), hover по любой иконке — включая вражеские — реплеит его по текущей доске.

Доки: новый Docs/combat-round-and-telegraph.md (по шаблону, с рецептом «добавить push-абилку»), переписаны секции ability-subsystem.md, запись в CHANGELOG, в ROADMAP четыре пункта Track C закрыты + 7 новых follow-up'ов (pull/dash, ring-push, анимация призрака, queue-simulation, инициатива, move-презентация, TelegraphStyle→SO).

Что проверить в редакторе (финальная приёмка за тобой)

Play mode: интенты врагов видны с начала раунда; уклонение от закоммиченного удара работает (промах); поворот героя перенацеливает подсветку и очередь; ghost на постановку и по hover; push отталкивает на 2 клетки. Отдельно смотри камеру/масштаб иконок (TelegraphStyle — константы, подкрутить легко).
